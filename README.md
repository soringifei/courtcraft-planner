# CourtCraft Planner

Age-specific basketball practice planner built with Next.js App Router, TypeScript, Tailwind CSS, and local typed seed data.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

## PDF

```bash
npm run generate:training-pdf
```

The generated PDF is served from `/basketball-training-plans.pdf`.
